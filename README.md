# Achadinhos 20

Primeira versão da vitrine de afiliados com produtos de até R$20.

## O que já funciona

- Layout responsivo para celular e computador
- Busca e filtros por categoria
- 13 departamentos com subcategorias
- Ordenação por popularidade, preço e novidades
- Botões externos preparados para links de afiliado
- Painel para cadastrar produtos
- Bloqueio de produtos cadastrados acima de R$20
- Persistência dos cadastros no navegador

## Próxima etapa

Preencher `config.js`, executar `supabase.sql` e criar o usuário proprietário no Supabase. Depois, conectar uma fonte oficial da Shopee para consultar preço e estoque.

## Acesso

- `Achadinhos-20-Celular.html`: loja pública somente leitura.
- `Painel-Achadinhos-20.html`: painel do proprietário protegido por login.

Para testar, abra `index.html` no navegador.

No celular Android, use o arquivo `Achadinhos-20-Celular.html`, que já contém visual e funcionamento completos em um único arquivo.
